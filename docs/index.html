ETlauncher

An Alien's Minecraft Launcher

A fast, modern Minecraft launcher that brings together modpacks from CurseForge, Modrinth, ATLauncher, FTB, and Technic in one place. Built with Tauri and Rust for native performance.

Features

5 Platforms in One

Browse and install modpacks from CurseForge, Modrinth, ATLauncher, FTB, and Technic without switching apps.

One-Click Install

Install mods with automatic dependency resolution. No more hunting for required libraries.

Smart Java

Automatically detects installed Java versions and selects the right one for each Minecraft version.

Multiple Accounts

Sign in with multiple Microsoft accounts and switch between them instantly.

Instance Management

Create, organize, and manage multiple instances with different versions and mod configurations.

Update Checking

Check for updates to your modpacks and individual mods. Stay current with one click.

Resource Pool

Mods, shaders, and resource packs are stored once and shared across instances. Save disk space automatically.

Native Performance

Built with Tauri and Rust for fast startup, low memory usage, and native OS integration.

Cross-Platform

Available for Windows, macOS, and Linux with consistent experience across all platforms.

Open Source

MIT licensed and open source. Inspect the code, contribute, or fork it for your own needs.
